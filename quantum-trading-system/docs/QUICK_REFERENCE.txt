9. INTEGER-ONLY RULES
================================================================================

✅ DO:
- Use integer literals: 100, 200, 1618
- Use integer division: x // y
- Store prices in cents: $100.25 → 10025
- Use Fibonacci/Lucas encodings
- Use integer timestamps (Unix time)
- Validate with IntegerValidator

❌ DON'T:
- Use float literals: 3.14, 0.5, 1.618
- Use float division: x / y
- Use math.sqrt(), math.log()
- Use np.float32, np.float64
- Use floating-point arrays

# Golden Ratio (φ ≈ 1.618)
phi = 1618 // 1000  # Integer approximation

# Pi (π ≈ 3.14159)
pi = 22 // 7  # Or 355 // 113 for better precision

10. FIBONACCI SEQUENCES
================================================================================

# Standard Fibonacci
F(0)=0, F(1)=1, F(2)=1, F(3)=2, F(4)=3, F(5)=5, F(6)=8, F(7)=13, F(8)=21...

# Lucas Numbers
L(0)=2, L(1)=1, L(2)=3, L(3)=4, L(4)=7, L(5)=11, L(6)=18, L(7)=29...

# Zeckendorf Representation
100 = F(11) + F(8) + F(6) + F(3) = 89 + 8 + 5 + 2

# Usage
from src.encoders.fibonacci_encoder import FibonacciEncoder
encoder = FibonacciEncoder(max_n=50)
fib_20 = encoder.get_fibonacci(20)  # Returns 6765
